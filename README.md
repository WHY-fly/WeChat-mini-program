# 汶川健康管家紧急呼救小程序
- 首页加载后自动开始 10 秒倒计时
- 点击“立即呼救”可直接拨打默认救援线路
- 10 秒内无人操作时自动拨打默认救援线路
- 保留社区中心和 120 备用线路

## 目录
- `config/emergency.js`：改标题、改联系电话、改自动呼救秒数
- `pages/index/`：首页页面和交互逻辑
- `project.config.json`：微信开发者工具项目配置

## 快速使用
1. 用微信开发者工具打开
2. 把 `project.config.json` 里的 `appid` 换成你自己的小程序 AppID
3. 打开 `config/emergency.js`，把“请替换为真实号码”改成汶川县当地真实电话
4. 真机预览测试倒计时和拨号

## 说明
- 开发者工具里可以看界面和倒计时，真实拨号要用真机测试
- 如果联系电话还是占位文案，页面会提示你先去配置号码，避免误拨
